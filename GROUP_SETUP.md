# Настройка отправки заявок в Telegram группу

## Как получить ID группы в Telegram

### Способ 1: Использование бота @userinfobot

1. Добавьте бота @userinfobot в вашу группу
2. Дайте боту права администратора (не обязательно, но может помочь)
3. Отправьте любое сообщение в группу
4. Перейдите в личные сообщения с @userinfobot
5. Бот покажет информацию о группе, включая её ID (это будет отрицательное число, например `-1001234567890`)

### Способ 2: Использование вашего бота

1. Добавьте вашего бота в группу
2. Дайте боту права на отправку сообщений
3. Отправьте любое сообщение в группу (можно просто написать "test")
4. Откройте в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
5. Найдите в ответе поле `"chat":{"id":-1001234567890}` - это и есть ID группы

### Способ 3: Использование бота @RawDataBot

1. Добавьте бота @RawDataBot в группу
2. Отправьте любое сообщение в группу
3. Бот ответит с полной информацией, включая ID группы

## Настройка .env файла

После получения ID группы, добавьте его в файл `.env`:

```env
# ID группы для получения заявок (приоритет, если установлено)
GROUP_CHAT_ID=-1001234567890

# ID инженера (используется, если GROUP_CHAT_ID не установлено)
ENGINEER_TELEGRAM_ID=103059062
```

**Важно:**
- ID группы всегда отрицательное число (начинается с `-100`)
- Если установлен `GROUP_CHAT_ID`, заявки будут отправляться в группу
- Если `GROUP_CHAT_ID` не установлен, заявки будут отправляться на `ENGINEER_TELEGRAM_ID`
- Бот должен быть добавлен в группу и иметь права на отправку сообщений

## Проверка работы

1. Создайте тестовую заявку через бота
2. Проверьте, что заявка появилась в группе
3. Если заявка не приходит, проверьте:
   - Правильность ID группы (должно быть отрицательное число)
   - Бот добавлен в группу
   - У бота есть права на отправку сообщений в группе
