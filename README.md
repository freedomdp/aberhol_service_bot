# Telegram Bot для KeyCRM

Минимальный Telegram бот для интеграции с KeyCRM. Бот работает напрямую с CRM системой, где операторы общаются с клиентами.

## Архитектура

- **Бот** принимает сообщения от пользователей
- **KeyCRM** управляет ботом напрямую через webhook
- **Операторы** общаются с клиентами через интерфейс KeyCRM
- Бот не собирает заявки, не ведет диалоги - только передает сообщения в KeyCRM

## Встановлення та запуск

1. Створіть віртуальне середовище:

```bash
python -m venv venv
```

2. Активуйте віртуальне середовище:
* Windows:
```bash
venv\Scripts\activate
```
* Linux/MacOS:
```bash
source venv/bin/activate
```

3. Встановіть залежності:

```bash
pip install -r requirements.txt
```

4. Створіть файл `.env` та заповніть необхідні змінні:

```env
TELEGRAM_TOKEN=your_telegram_bot_token
```

5. Налаштуйте webhook в KeyCRM:

- Войдите в KeyCRM
- Настройки → Интеграции → Telegram
- Укажите URL вашего бота (если используется webhook)
- Или настройте прямое подключение бота к KeyCRM

6. Запустіть бота:

```bash
python src/main.py
```

## Как это работает

1. Пользователь отправляет сообщение боту
2. Бот логирует сообщение
3. KeyCRM получает сообщение через webhook или прямое подключение
4. Оператор видит сообщение в KeyCRM и отвечает
5. KeyCRM отправляет ответ пользователю через бота

## Логирование

Все сообщения логируются в файл `logs/bot_YYYYMMDD.log`

Этот бот не собирает заявки и не ведет диалоги. Вся коммуникация происходит через KeyCRM. Бот служит только мостом между Telegram и KeyCRM.
